# 02_フォルダ構成

## 推奨構成

```text
METAMI/
│
├── docs/
│   ├── 00_プロジェクト概要.md
│   ├── 01_要件定義_UI設計.md
│   ├── 02_フォルダ構成.md
│   ├── 03_AI支援開発・Git運用ガイド.md
│   ├── 04_ロードマップ.md
│   ├── 05_AI支援開発ガイド.md
│   └── CHANGELOG.md
│
├── src/
│   ├── ui/
│   ├── metadata/
│   ├── models/

│
├── tests/
├── assets/

├── README.md

```

## 各領域の責務
| 領域 | 主な責務 |
|---|---|
| src/ui/ | ウィンドウ、レイアウト、ダイアログ、表示制御 |
| src/metadata/ | PNG、WEBP、MP4からのメタデータ抽出・正規化 |
| src/models/ | ファイル情報やメタデータを表すデータ構造 |
| src/utils/ | パス、ログ、共通処理 |
| tests/ | 自動テスト |
| assets/ | アイコン等の静的素材 |
| sample/ | 動作確認用のサンプルファイル |

## AIに委ねてよい範囲
以下は、仕様を満たす限りAI開発エージェントが変更・追加してよい。

- `src/` 以下の詳細なファイル分割
- クラス名・関数名
- 内部処理の分離
- テスト用ファイル
- ログ機能
- 型ヒント
- 小規模な共通化
- PySide6で一般的な実装上必要となる補助ファイル

## 事前確認が必要な変更
以下を行う場合は、ユーザーへ理由と案を示す。

- 新しい大分類フォルダを追加する
- 大規模な構成変更をする
- GUIフレームワークを変更する
- データベースや常駐サービスを導入する
- インストール容量が大きい依存関係を追加する
- ユーザーファイルを書き換える機能を追加する

## 更新ルール
実際の構成が本書と大きく変わった場合は、実装と同じ作業内で本書も更新する。
軽微なファイル追加まで毎回細かく記載する必要はない。

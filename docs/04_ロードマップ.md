# M.E.T.A.M.I. ロードマップ

## 現在地

- アプリ名：**M.E.T.A.M.I.**
- 読み方：めたみ
- キャラクター：タリア、めたみ
- 現在の状態：**Ver1.0.0 リリース候補**
- Pythonソース形式の公開準備と別PC検証は完了
- GitHubのPrivateリポジトリへ公開候補を配置済み
- Publicへの変更、`v1.0.0`タグ、GitHub Releaseは未実施

M.E.T.A.M.I.は、画像や動画のメタデータを確認し、評価、タグ、メモ、
ユーザータイトルで自分用に整理するWindows向けアプリです。ユーザー情報は
SQLiteへ保存し、原本画像・動画は変更しません。

## Ver0.8.9　統合確認と安定化（完了）

Ver0.8系で追加した機能をまとめて確認し、公開準備へ進める状態にしました。

### 読み込みとカード表示

- PNG、WEBP、MP4の一覧、サムネイル、プレビューを統合確認
- `width >= height`は横型、`height > width`は縦型として表示
- 1:1素材は横型カードとして表示
- 16:9、9:16、4:3、3:4、3:2、2:3とその他の比率を確認
- アスペクト比を維持し、全体表示を優先
- 余白を許容し、素材を勝手にトリミングしない
- タイトル、評価、タグ、メモ抜粋をカード寸法を崩さず表示
- 長い文字列は省略し、一覧のスクロールを維持

### 詳細表示と保存

- プレビュー、基本情報、Workflow、JSONの連動を確認
- 評価、タグ、メモのSQLite保存と再起動後の復元を確認
- missing状態、再関連付け、METAMI記録削除を確認
- DB状態を`Online`、`Error`、`Offline`で実状態に連動
- DB障害時も可能な範囲でGUIを継続
- メモ入力欄の案内表示が入力操作へ重ならないよう調整

### 評価案内

- 未評価の静止画は一定時間後に1回だけ案内
- 未評価の動画は75％到達時または再生終了時に1回だけ案内
- 評価済みの素材では表示せず、評価後は案内を消去
- 動画再生中や入力操作中の誤表示を防止

### 表示・安全性

- 最小実用サイズ、通常サイズ、最大化、フルHD、ワイド画面を確認
- Windows表示倍率100％、125％、150％を確認対象として整備
- 文字、ボタン、タブ、カード、右側パネルの重大な崩れを修正
- 新規DBと既存DBの起動、既存データ保持を確認
- 原本の内容、メタデータ、名前、場所を変更しないことを確認

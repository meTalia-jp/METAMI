# M.E.T.A.M.I. Ver0.8.9 ロードマップ・Codex実装指示

## Ver0.8.9　統合試験とバグ修正

### 目的

Ver0.8.7〜Ver0.8.8で実装した機能を統合確認し、Ver0.9.0の公開準備へ進める状態にする。

このバージョンでは、原則として新機能を追加しない。
確認中に見つかった不具合、表示崩れ、既存機能の退行だけを修正する。

---

## 1. 確認対象

### 対応形式

- PNG
- WEBP
- MP4

### 縦横比

- 16:9
- 9:16
- 1:1
- 4:3
- 3:4
- 3:2
- 2:3
- その他の横長素材
- その他の縦長素材

### カード表示

- 横長素材は横型カード
- 縦長素材は縦型カード
- 1:1素材は横型カード
- 画像・動画はアスペクト比を維持
- 全体表示を優先
- 余白を許容
- 勝手にトリミングしない
- タイトル、評価、タグ、メモ抜粋が正しく表示される
- カードの高さや幅が極端に崩れない
- スクロールが正常に動作する

### 右側詳細表示

- プレビュー
- 基本情報
- 実際のファイル名
- フルパス
- 評価
- タグ
- メモ
- Workflow
- JSON
- DB状態表示

### 保存機能

- ユーザータイトル
- 評価
- タグ
- メモ
- missing状態
- 再関連付け
- METAMI記録削除

### 評価案内

- 初期状態では追加メッセージを表示しない
- 未評価の静止画では一定時間後に表示
- 未評価の動画では再生終了時または75％到達後に表示
- 同じファイルでは起動中1回だけ
- 評価済みでは表示しない
- 評価後に案内文が消える
- 評価案内がプレビューや操作を妨げない

### DB

- 新規DBで起動
- 既存DBで起動
- 既存データを保持
- 正常時は `DB ● Online`
- 障害時は `DB ● Error` または `DB ○ Offline`
- DB障害でアプリ全体が異常終了しない

### missing管理

- 元ファイルが存在しない場合にmissingとして扱う
- missing状態が一覧へ反映される
- 再関連付けが動作する
- METAMI記録削除が動作する
- 誤って原本ファイルを削除しない

### 原本保護

- PNG、WEBP、MP4を変更しない
- メタデータを書き換えない
- ファイル名を変更しない
- ファイルを移動しない
- ファイルを削除しない

# Codexへの実装指示

```text
Ver0.8.9として、M.E.T.A.M.I.の統合試験とバグ修正を行ってください。

このバージョンでは新機能を追加しないでください。
Ver0.8.7〜Ver0.8.8で実装した機能の統合確認、表示調整、
不具合修正、例外処理、テスト追加だけを行ってください。

現在のGUI、SQLiteデータ、縦横カード表示、
評価、タグ、メモ、missing、Workflow、JSON、
評価案内、DB状態表示を維持してください。

1. 対応形式の確認

以下を読み込んで確認してください。

- PNG
- WEBP
- MP4

各形式について、
- 一覧へ表示される
- サムネイルまたはプレビューが表示される
- 基本情報が表示される
- WorkflowとJSONが取得可能な場合は表示される
- 読み込み失敗時にアプリ全体が異常終了しない
ことを確認してください。

2. 縦横比とカード表示

以下を確認してください。

- 16:9
- 9:16
- 1:1
- 4:3
- 3:4
- 3:2
- 2:3
- その他の横長素材
- その他の縦長素材

判定ルール:
- width >= height は横型カード
- height > width は縦型カード
- 1:1は横型カード

共通仕様:
- アスペクト比を維持する
- 全体表示を優先する
- 余白を許容する
- 勝手にトリミングしない
- 横型カードと縦型カードで情報が欠けない
- タイトル、評価、タグ、メモ抜粋が正しく表示される
- カードの外寸が極端に崩れない
- スクロールが正常に動作する

3. 保存・復元

以下がSQLiteへ保存され、再起動後に復元されることを確認してください。

- ユーザータイトル
- 評価
- タグ
- メモ
- missing状態

既存DBを壊さないでください。
スキーマ変更が必要な場合は、安全なマイグレーションを行ってください。

4. 評価案内

以下を確認してください。

- ファイルを開いた直後は追加メッセージを表示しない
- 未評価の静止画では15〜20秒後に案内を表示する
- 未評価の動画では再生終了時または75％到達後に案内を表示する
- 同じファイルではアプリ起動中に1回だけ表示する
- 評価済みファイルでは表示しない
- 評価すると案内文を消す
- 動画再生中、メモ入力中、タグ編集中に誤表示しない
- 案内文がプレビューや操作部へ重ならない

5. DB状態表示

以下を実状態に連動させてください。

- 正常時: DB ● Online
- エラー時: DB ● Error
- 利用不可時: DB ○ Offline

DB障害時でも、可能な範囲で画面を表示し、
原因が分かるログまたはエラーメッセージを出してください。

6. missing管理

以下を確認してください。

- 元ファイルが存在しない場合にmissingとして表示される
- 再関連付けが動作する
- METAMI記録削除が動作する
- 記録削除で原本ファイルを削除しない
- missing処理で既存の評価、タグ、メモを失わない

7. 右側詳細表示

以下を確認してください。

- プレビュー
- 基本情報
- 実ファイル名
- フルパス
- 評価
- タグ
- メモ
- Workflow
- JSON
- DB状態表示

長いファイル名、長いパス、長いタグ、長いメモでも
画面が極端に崩れないようにしてください。

8. 表示倍率とウィンドウサイズ

以下で確認してください。

- Windows表示倍率100％
- 125％
- 150％
- 最小実用サイズ
- 通常サイズ
- 最大化
- フルHD
- ワイド画面

確認項目:
- 文字切れ
- ボタン切れ
- タブ切れ
- カードの重なり
- パネルのはみ出し
- スクロール不能
- 評価案内の位置ずれ
- 高DPI時のアイコン崩れ

実行環境で確認できない表示倍率は、
コード上の高DPI対応とレイアウト制約を確認し、
未確認項目として報告してください。

9. 原本保護

M.E.T.A.M.I.から以下を行わないでください。

- 原本画像・動画の内容変更
- メタデータの書き換え
- ファイル名変更
- ファイル移動
- ファイル削除

METAMI記録削除はSQLite上の記録だけを対象としてください。

10. 自動試験

既存テストを実行し、不足する場合は次のテストを追加してください。

- PNG、WEBP、MP4の読み込み
- 横型カード判定
- 縦型カード判定
- 1:1の横型判定
- 特殊比率の判定
- アスペクト比維持
- タイトル保存・復元
- 評価保存・復元
- タグ保存・復元
- メモ保存・復元
- メモ抜粋
- 評価案内の表示条件
- 評価後に案内が消える
- 評価済みでは案内が出ない
- missing状態
- 再関連付け
- METAMI記録削除
- 新規DB起動
- 既存DBデータ保持
- 原本ファイル非変更

11. 修正方針

不具合が見つかった場合のみ修正してください。
大規模なリファクタリングは行わないでください。
既存の正常動作を変更しないでください。
絶対パスをコードへ固定しないでください。
不要な依存ライブラリを追加しないでください。

12. 最終報告

実装後に日本語で以下を報告してください。

- 実施した確認項目
- 発見した不具合
- 不具合の原因
- 修正内容
- 変更ファイル
- 自動試験結果
- 手動確認結果
- 確認できなかった項目
- 既知の制約
- Ver0.9.0へ進む際の注意点

GitコミットとGitHubへのpushは行わないでください。
```

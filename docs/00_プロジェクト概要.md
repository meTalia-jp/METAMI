# 00_プロジェクト概要

## 名称
- アプリ名: M.E.T.A.M.I.
- 通常略記: METAMI
- 読み: めたみ
- 正式名称: Metadata Exploration & Tag Analysis with Media Insight
- キャラクター: タリア ＆ めたみ

## 目的
ComfyUI等で生成した画像・動画（PNG / WEBP / MP4）に埋め込まれた生成情報
（メタデータ）を、閲覧・検索・管理できる日本語GUIアプリを作成する。

## 対象環境
- OS: Windows 11
- 言語: Python 3.12以上
- GUIフレームワーク: PySide6
- 開発支援AI: Codex、Continue、その他のAI開発エージェントを併用可能

## このアプリで実現すること
- 画像・動画に埋め込まれた生成メタデータを読み取り、見やすく表示する
- フォルダ内の対象ファイルを一覧表示する
- メタデータの内容による検索・絞り込みを行う
- 日本語話者がコードを読まなくても操作・確認できるGUIを提供する

## 対象メタデータの例
- Prompt
- Negative Prompt
- Workflow
- Seed
- Model
- Sampler
- Scheduler
- LoRA
- jp_prompt
- その他のJSON情報

## 初期リリースでは対象外とする機能
次の機能は、ユーザーが明示的に追加を決定するまでは実装対象外とする。

- AI画像解析（Florence、JoyCaption等）
- OCR
- 自動翻訳
- 画像・動画生成
- クラウドへの自動アップロード
- ファイル内容の自動変更・削除

これはAIの実装手段を過度に制限するための禁則ではなく、
アプリの目的と開発範囲を明確にするための境界である。

## 開発方針
- 仕様を満たす実装方法は、AI開発エージェントの合理的な判断に委ねる
- 小規模な内部設計、関数分割、命名、例外処理、テスト追加はAIが判断してよい
- ユーザー体験、対応形式、保存データ、主要機能を変える場合は事前確認する
- 各バージョンは実際の動作確認後に完成とする

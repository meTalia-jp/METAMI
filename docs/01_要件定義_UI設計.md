# 01_要件定義・UI設計

## 対応ファイル形式
| 形式 | 対応開始バージョン |
|---|---|
| PNG | Ver0.3 |
| WEBP | Ver0.4 |
| MP4 | Ver0.5 |

Ver0.1〜0.2ではメタデータ解析を実装しない。
Ver0.3から実ファイルに埋め込まれたメタデータを読み取る。

## 対応メタデータ項目
初期対応項目は以下とする。

- Prompt
- Negative Prompt
- Workflow
- Seed
- Model
- Sampler
- Scheduler
- LoRA
- jp_prompt
- その他JSON

項目名や格納構造が異なる場合でも、取得可能な情報を失わず表示できる設計を優先する。
未知の項目は「その他」としてキーと値を表示できるようにする。

## UIの基本方針
- 表示言語は日本語
- 横長モニターを活用する
- 初心者でも現在の状態が分かる表示にする
- エラー時は技術用語だけで終わらず、日本語で原因と次の操作を示す
- 一度に情報を詰め込みすぎず、必要に応じて折りたたみやタブを利用する
- Verごとの実装範囲を優先し、完成形UIを一度に実装しない

## Ver1.0時点の想定レイアウト

```text
┌──────────────────────────────────────────────────────────────┐
│ メニューバー（ファイル / 表示 / ヘルプ）                    │
├──────────────┬──────────────────────┬────────────────────────┤
│ フォルダ・    │ プレビュー・          │ メタデータ詳細          │
│ ファイル一覧  │ 選択ファイル情報      │ Prompt / Seed / Model等 │
├──────────────┴──────────────────────┴────────────────────────┤
│ ステータスバー（件数、選択パス、処理状況、エラー）          │
└──────────────────────────────────────────────────────────────┘
```

このレイアウトは完成形の方向性であり、内部構成やウィジェットの選択は
AI開発エージェントがPySide6の一般的な設計に沿って決定してよい。

## 段階的なUI実装
- Ver0.1: 起動可能な最小GUI
- Ver0.2: ファイル・フォルダの受け取りとパス表示
- Ver0.3: PNGメタデータの読取・表示
- Ver0.4: WEBP対応
- Ver0.5: MP4対応
- Ver0.6: 一覧・サムネイル表示
- Ver0.7: 検索・絞り込み
- Ver1.0: 安定化、エラー処理、配布準備

## 操作フロー
1. アプリを起動する
2. メニューまたはドラッグ＆ドロップでファイル・フォルダを指定する
3. 対象ファイルを選択する
4. プレビューとメタデータを確認する
5. 必要に応じて検索・絞り込みを行う

## 非機能要件
- Windows 11で正常に起動する
- Python 3.12以上で動作する
- 通常の起動は数秒以内を目安とする
- 数千ファイルを扱う場合でも、長時間UIが固まり続けない設計を目指す
- 読み取り失敗したファイルがあっても、アプリ全体が終了しない
- ユーザーのファイルを勝手に変更・削除しない

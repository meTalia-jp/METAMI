# M.E.T.A.M.I. ライセンス方針

この文書は、Ver1.0.0公開候補で確定したライセンス判断を記録します。
法的助言ではありません。

## 1. 分けて扱う対象

### ソースコード

主な対象:

- `src/**/*.py`
- `tests/**/*.py`
- `run_metami.bat`
- 設定・説明用テキスト

### キャラクター・ロゴ・画像素材

主な対象:

- `src/assets/**`
- `docs/images/**`
- 将来追加するスクリーンショット、ロゴ、配布用画像

ソースコード用ライセンスを選んでも、画像素材へ自動的に同じ条件を
適用しない方針とします。画像素材は制作者、生成サービスの規約、
編集者、公開・再配布の可否を個別に確認します。

### 外部ソフトウェア

Ver1.0.0では次の公開方式を採用します。

- M.E.T.A.M.I.のソースコードをMIT LicenseでGitHub公開する
- Pythonソース形式で配布する
- PySide6、Shiboken6、Qtのバイナリをリポジトリへ同梱しない
- 利用者が`requirements.txt`からPyPI経由で導入する
- Qt／PySide6本体を改変しない
- GPL専用のQtモジュールを使用しない
- Qt for PythonがLGPLv3／GPLv3または商用ライセンスで提供されることを
  READMEとNOTICEへ記載する

M.E.T.A.M.I.のMIT Licenseは、PySide6、Shiboken6、Qtには適用されません。
将来、実行ファイル化してQtライブラリを同梱・再配布する場合は今回の
判断対象外とし、LGPLv3を含む適用条件を改めて確認します。

## 2. ソースコード用ライセンス

ソースコードにはMIT Licenseを適用します。

```text
Copyright (c) 2026 meTalia-jp
```

正式なライセンス全文はルート`LICENSE`に配置します。著作権表示と
許諾表示を保持することを条件に、利用・複製・改変・結合・公開・配布・
サブライセンス・販売等を許可します。

## 3. MIT License対象外

タリア、めたみ、ロゴ、キャラクター画像、関連イラスト、高解像度原画、
制作データはMIT License対象外です。非商用二次創作等には
`src/assets/README.md`のキャラクター利用方針を適用します。

## 4. 公開時の確認事項

- 公開画像に個人情報、ローカルパス、私物データを含めない
- 第三者素材や公開禁止データがGit履歴へ混入していないことを確認する
- キャラクターの商用利用相談はmeTalia-jpが個別に判断する

開発用GUIモックアップ4画像は公開しません。キャラクター画像、公開画像、
開発用モックアップに第三者素材が含まれていないことを権利者が確認済みです。
公開用画像は`docs/images/`の3画像に限定します。

`LICENSE`、`NOTICE.md`、`src/assets/README.md`および本文書を一組として
公開し、ソースコードと画像素材の条件を混同しないようにします。

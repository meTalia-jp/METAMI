# 公開画像

Ver1.0.0リリース候補のREADMEへ掲載する公開用画像です。
これらの画像はソースコードのMIT License対象外です。

| ファイル | 用途 | 公開前確認 |
|---|---|---|
| `metami-main.png` | メイン画面 | パス・実ファイル名・実フォルダー名・個人情報なし |
| `project-message-ja.png` | 日本語ライセンス説明 | C2PA来歴情報あり、個人情報・パス・EXIFテキストなし |
| `project-message-en.png` | 英語ライセンス説明 | C2PA来歴情報あり、個人情報・パス・EXIFテキストなし |

日本語版・英語版の`caBX`チャンクは、生成経緯を示すC2PA Content
Credentialsです。秘密情報やローカル情報ではないため、来歴情報として
保持しています。

高解像度原画、レイヤー付き制作データ、個人用スクリーンショットは
このフォルダーへ配置しません。
